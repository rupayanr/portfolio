# Portfolio

Interactive 3D developer portfolio built with Spline.

![Portfolio Preview](preview.png)

## ✨ Features

- **Interactive 3D Room** — Click objects to explore projects
- **Time-Aware Lighting** — Room changes based on your local time
- **Ambient Audio** — Sound effects and lo-fi music player
- **Mobile Friendly** — Works on modern iPhones

## 🛠 Tech Stack

- React + TypeScript
- Spline (3D)
- Howler.js (Audio)
- Tailwind CSS
- Vite

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🎯 Room Objects

| Object | Action |
|--------|--------|
| Monitor | Opens LiveDoc |

| Laptop | Opens Vox |
| Arcade Cabinet | Play retro game |
| Calculator | Scientific calculator |
| Vinyl Player | Lo-fi music |
| Pinboard | View resume |
| Window | GitHub & LinkedIn |
